# Roster (84 Pokémon)

- **84 species ↔ 84 kits** in `packages/content/{species,kits}/<faction>.json`, generated by
  `scripts/import-roster.mjs` from the owner's sheet.
- **Tiers:** Rarity → tier; Mythic / Origin / Shiny Mythic → `mythic`. Ladder seen in M10.6:
  rare → epic → legendary → supreme → mythic (stat totals ~1,605 → 2,090 → 2,972 → 3,963 → 5,192).
- **Factions (6):** ember (Fire), tide (Water), grove (Grass), shade (Dark), volt/frost (Light,
  alternating). Faction sizes 18/19/19/7/7/14 — the validator only requires ≥1 per faction.
- **Classes:** striker / guardian / adept (physical → striker, magical → adept).
- **Stages:** generated `X`, `X Prime`, `X Zenith` (the sheet only lists final forms).
- **Skills:** all 84 ported faithfully in M9 — see [skill kits](skill-kits.md).
